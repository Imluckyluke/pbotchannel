# Session Backup Bot

## نصب لوکال (اختیاری)
```bash
pip install -r requirements.txt
cp .env.example .env
python bot.py
```
دیگه لازم نیست از `generate_session.py` استفاده کنی؛ لاگین سشن کاملاً از
داخل خود ربات با کلید شیشه‌ای انجام میشه (پایین‌تر توضیح داده شده).
`generate_session.py` فقط به عنوان یه راه جایگزین/دستی نگه داشته شده.

## دیپلوی روی Railway
1. یه پروژه‌ی جدید بساز و این ریپازیتوری/فولدر رو بهش وصل کن (یا از طریق
   Railway CLI آپلود کن). ریلوی با وجود `Procfile` و `requirements.txt`
   خودش تشخیص میده و به عنوان یه **Worker** اجراش میکنه (نه Web Service،
   پس نیازی به پورت نیست).
2. توی تب **Variables** این متغیرها رو بذار:
   - `API_ID`
   - `API_HASH`
   - `BOT_TOKEN`
   - `ADMIN_IDS`
   - `DB_PATH` = `/data/data.sqlite3`
3. یه **Volume** بساز و به مسیر `/data` مونت کن (Settings → Volumes).
   این خیلی مهمه: بدون Volume، سر هر ری‌دیپلوی سشن و تنظیماتی که از پنل
   وارد کردی پاک میشه و باید دوباره لاگین کنی.
4. Deploy بزن. توی لاگ باید ببینی `bot started`.
5. برو تو ربات معمولی‌ات، `/panel` رو بزن و طبق بخش زیر لاگین کن.

## لاگین سشن از داخل ربات (بدون نیاز به سرور جدا)
از پنل (`/panel`) دو راه برای وارد کردن سشن هست:

**۱. ورود با شماره** (روی **🔑 ورود با شماره** بزن):
1. شماره تلفن اکانت سشن رو با فرمت بین‌المللی بفرست (مثلا `+989123456789`).
2. کدی که تلگرام میفرسته رو با **کلیدهای شیشه‌ای** (۰ تا ۹، ⌫، ✅ تایید)
   وارد کن — نیازی به تایپ نیست.
3. اگه اکانت تایید دو مرحله‌ای (2FA) داشته باشه، ربات خودش تشخیص میده و
   ازت میخواد رمز رو به صورت پیام متنی بفرستی؛ بلافاصله بعد از خوندن،
   پیام حاوی رمز حذف میشه.
4. بعد از موفقیت، استرینگ سشن داخل دیتابیس ذخیره میشه، کلاینت سشن همون
   لحظه وصل میشه (دیگه لازم نیست ری‌استارت کنی)، و خودِ Session String هم
   توی پیام تاییدیه بهت نشون داده میشه که برای دفعات بعد نگهش داری.

**۲. ورود مستقیم با Session String** (روی **📋 ورود مستقیم با Session
String** بزن): اگه از قبل یه Session String داری (مثلاً از همون پیام
تاییدیه‌ی بالا، یا از `generate_session.py`)، کافیه بفرستیش؛ ربات باهاش
وصل میشه و ذخیره‌اش میکنه، بدون نیاز به شماره و کد.

⚠️ Session String معادل دسترسی کامل به همون اکانت تلگرامه؛ جایی نگهش دار
که فقط خودت بهش دسترسی داری.

## بقیه‌ی تنظیمات (پنل کلیدی داخل ربات)
دستور `/panel` (یا `/start`) رو بزن؛ یه منوی دکمه‌ای باز میشه با این گزینه‌ها:
- ربات X
- ربات بکاپ
- کلمه‌ی تبدیل به لینک
- فاصله زمانی مانیتور (ثانیه)
- سقف روزانه مانیتور (فایل)
- قالب پست خودکار
- ورود با شماره / Session String
- مدیریت کانال‌ها (مقصدهای پست)
- 📡 چنل‌های مانیتور (مبدأهایی که ازشون فایل گرفته میشه)
- مدیریت ادمین‌ها (افزودن/حذف)
- نمایش کامل تنظیمات

## مانیتور خودکار چنل (ادغام‌شده از ربات watcher)
همه‌چیز حالا با همون **یک ربات اصلی + یک سشن‌بات** انجام میشه؛ نیازی به
اجرای دو تا پروژه‌ی جدا نیست.

1. از پنل، روی «📡 چنل‌های مانیتور» بزن و لینک/یوزرنیم/آیدی چنل مبدا رو
   اضافه کن (سشن باید از قبل لاگین باشه تا بتونه عضو چنل بشه).
2. یه پروسه‌ی پس‌زمینه هر `فاصله زمانی مانیتور` ثانیه یک‌بار، آخرین پیامِ
   حاوی فایل هر چنل مانیتور رو (اگه قبلاً گرفته نشده باشه) با سشن دانلود
   می‌کنه، **همون کپشنی که خود پست مبدا داشت** رو هم برمی‌داره، دقیقاً
   همون مسیر قبلی رو طی می‌کنه (ربات X → لینک → ربات بکاپ → لینک بکاپ) و
   بعد با همون کپشن (بعد از جایگزینی «ایدی چنل» و هایپرلینک کردن کلمه‌ی
   تریگر با لینک بکاپ) خودش پست رو توی همه‌ی «کانال‌های مقصد» می‌ذاره —
   بدون نیاز به دخالت دستی.
3. اگه پست مبدا کپشن نداشت، به‌جاش از «قالب پشتیبان» (تنظیم‌شده از پنل)
   استفاده میشه؛ اگه اونم خالی بود، لینک بکاپ برای ادمین‌ها فرستاده میشه
   تا دستی پست کنن.
4. سقف `سقف روزانه مانیتور` تعداد فایل در ۲۴ ساعت رو محدود می‌کنه.
5. اگه کانال مقصدی تنظیم نشده باشه یا ارسال با خطا مواجه بشه، ربات
   به‌جاش برای همه‌ی ادمین‌ها پیام می‌ده (شامل لینک بکاپ) تا دستی پست کنن.
6. فرآیند دستی قبلی (فرستادن فایل مستقیم به ربات و بعد کپشن با کلمه‌ی
   تریگر) دست‌نخورده باقی مونده و همچنان کار می‌کنه.

روی هر گزینه بزنی، مقدار فعلیش رو نشون میده و ازت میخواد مقدار جدید رو
به صورت پیام بفرستی؛ همون لحظه ذخیره میشه و برمیگرده به منوی اصلی.
هیچ دستور متنی‌ای لازم نیست، همه چیز کلیدیه.

پیش‌فرض دکمه‌های ربات بکاپ همون متن‌هایی هست که گفتی (آپلود فایل / تکی /
بازگشت به منو اصلی)؛ اگه دقیقاً همونا باشه نیازی به تغییر نیست.

## استفاده
1. فایل رو برای ربات معمولی بفرست.
2. ربات فایل رو میده به ربات X، لینک میگیره، بعد میره تو ربات بکاپ
   (/admin → دکمه آپلود فایل → دکمه تکی → فرستادن لینک → گرفتن لینک بکاپ →
   دکمه بازگشت به منو اصلی) و لینک بکاپ رو برات میفرسته.
3. حالا پیام نهایی رو با همون فرمتی که میخوای بفرست، مثلاً:
```
سلام امروز اومدیم با...

مشاهده

ایدی چنل
```
   ربات کلمه‌ی «مشاهده» رو به لینک بکاپ هایپرلینک میکنه و «ایدی چنل» رو با
   مقدار `channel_display` جایگزین میکنه و پیام رو مستقیم توی چنل تنظیم‌شده پست میکنه.

## نکته مهم
- ربات معمولی باید ادمین چنل مقصد باشه با اجازه‌ی ارسال پیام.
- اکانت سشن (یوزربات) باید از قبل توی هر دو ربات (X و بکاپ) استارت زده باشه
  و اگه ربات بکاپ نیاز به دسترسی خاصی (مثل ادمین بودن یا عضویت) داره از قبل ردیف باشه.
- تعامل با ربات بکاپ کاملاً بر اساس **موقعیت دکمه‌ها** انجام میشه، نه متنشون:
  هر بار اول `/start` بعد `/admin` فرستاده میشه، بعد کلید «آپلود فایل» (ردیف
  دوم، کلید دوم)، بعد کلید «تکی» (ردیف اول، کلید اول سمت چپ)، و در آخر بعد از
  گرفتن لینک بکاپ، کلید «بازگشت» (تک دکمه‌ست، ردیف اول/کلید اول) هم کلیک
  میشه. اگه چیدمان کیبورد ربات بکاپ فرق داره، مقادیر `i` و `j` رو توی تابع
  `get_backup_link` داخل `bot.py` عوض کن.
